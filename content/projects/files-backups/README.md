# Files & Backups

A native file and backup browser for iPhone, iPad, and Mac, with explicit provider configuration.

Browse configured SMB, WebDAV, SFTP, local Mac folders, or Home Services storage. Manage transfers, inspect file details, and use provider-supported backup and restore features. Home Services adds managed Trash and snapshot browsing; capabilities are specific to each provider.

Version 0.1 (4) refreshes the private TestFlight beta with current Connected Apps support. No public App Store download or open beta link is advertised. Summary-sharing consent is separate from storage credentials, file operations, and restore permissions.

The companion backup agent and Home Services are independent installations. Installing the app does not install a server or begin backups. Real restores and provider/hardware checks remain separate from build and permission tests.
