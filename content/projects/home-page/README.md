# Home Page

A native Mac dashboard for apps, attention, and Shortcuts. Requires macOS 14.4 or later.

Launch installed applications and websites, organize favorite launchers, and connect named Shortcuts. Participating apps can optionally share local status summaries.

The first App Store release is pending approval. No verified public download is advertised.
