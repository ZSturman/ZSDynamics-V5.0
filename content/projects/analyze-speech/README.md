# Analyze Speech

Local Python transcript and audio analysis with dependency-free core commands and synthetic tests.

## Implementation

A standard-library CLI computes transcript statistics and WAV measurements. FFmpeg conversion and optional pitch analysis extend the core without uploading source recordings.

## Source and testing

[Public source and setup](https://github.com/ZSturman/Analyze-Speech)

[Validation and next steps](https://github.com/ZSturman/Analyze-Speech/blob/main/docs/NEXT_STEPS.md)

## Current limitations

Research tools, not clinical speech assessment. Real recordings, transcripts and derived personal outputs are deliberately excluded. FFmpeg is needed for formats other than supported WAV input.
