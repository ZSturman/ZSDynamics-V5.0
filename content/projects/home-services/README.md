# Home Services

A small server runs continuously on a Raspberry Pi. It handles managed camera recordings, backup status and recovery, and selected app handoffs. The Mac status console shows disk space, schedules and recent jobs.

Mobile clients use scoped access for the services they need. When the Mac is asleep, the Pi can hold selected edits or encrypted captures for later processing. Publication and other source-owned decisions stay with the apps that own them.

The architecture diagram shows how the apps connect to this private deployment.
