# Finder Workspace Extensions

Browse project folders in Finder and open an overview, add a task, or start a work session from the project menu. Project View adds sortable columns for metadata Finder cannot display, such as priority, phase and open tasks. Export a project card to inspect a snapshot with Quick Look.

Finder Workspace Extensions owns linked project status, phase, domain, priority and maintenance. Better Workspace mirrors those values and owns tasks and ideas. Neither app reads the other’s database. The recordings show the native workflow in a sample collection before the November status expansion.

## Capture an idea without losing its draft

Finder’s Capture Idea opens Better Workspace’s shared composer. The 1.0.5 capture
update keeps file-picker navigation active, copies Finder-pasted movies as
original attachments, shows full errors, and keeps text when removing a file.
Completed idea saves request a Better Workspace notification. Save before quitting:
drafts remain in memory.

Finder Workspace Extensions 0.1.1 (2) is a signed, notarized development preview for
macOS 14.4 or later, with Apple silicon and Intel binaries. It remains a separate
Mac download; it has no TestFlight or App Store edition. Enable only the extensions
and workspace roots you want. Clean-user installation, Intel runtime and broader
