# Opportunity Discovery

Start with a public activity, investigate a possible contribution, and decide if it is worth pursuing. The review queue brings together source evidence, a possible offer, the gaps in that offer and a next action. A reviewer can request more research, defer, reject, or prepare a draft.

The project covers software, research support, electronics, fabrication and creative work. It uses sources such as public nonprofit records and NSF awards. The source record stays attached to the opportunity so a reader can distinguish the documented activity from the proposed work.

The dashboard and iPhone client are in private use. The example shows a fictional exhibit and review decision.
