# Warehouse Wanderer

An Android/iOS warehouse-visit passport with local visit tracking, wishlists and targeted UI tests.

## Implementation

Expo/React Native screens use local persistence and warehouse data providers. Config plugins preserve native setup when Expo regenerates Android and iOS hosts.

## Source and testing

[Public source and setup](https://github.com/ZSturman/Warehouse-Wanderer)

[Validation and next steps](https://github.com/ZSturman/Warehouse-Wanderer/blob/main/docs/NEXT_STEPS.md)

## Current limitations

Independent, unofficial prototype with no retailer affiliation. Prior Android emulator flows passed; no physical Android acceptance is established. Native builds require a compatible JDK/Android SDK. Optional map features need your own API key.
